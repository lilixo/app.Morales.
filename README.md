# apppMorales

Proyecto completo del examen final de Diseño Web, desarrollado en Angular.

## Ejecutar

1. Instala Node.js compatible con Angular 22 (Node 24.15 o superior de la rama 24).
2. Abre esta carpeta en VS Code.
3. Ejecuta `npm ci`.
4. Ejecuta `npm start -- --open`.

También puedes usar `npx ng serve -o`.

## Verificar

- `npm run build`: compila la aplicación.
- `npm test -- --watch=false`: verifica navegación, carrusel y formulario.

## Contenido

Cabecera y pie compartidos, página Principal con carrusel de dos imágenes y página Contáctenos con todos los campos del pedido. Cancelar y Enviar son botones de muestra sin funcionalidad. Se conservan las imágenes originales.

El proyecto Angular se llama `apppMorales`; el nombre técnico de npm es `appp-morales` porque npm requiere minúsculas.

Las dependencias se instalan con npm; no se incluye node_modules. Para la entrega reducida solicitada por el profesor, usa únicamente src y public.
